## 1. 요약

1. 팀 발표자료를 바탕으로 주제를 **'DAEGU, IN A DAY — 대구를 경험하는 새로운 하루'**로 확정한다. 커피와 베이커리를 **첫 접점(입구)**으로 삼고, 취향 커뮤니티(독서·대화)와 동네 산책을 묶어 **대구에서 하루를 머물 이유**를 만드는 로컬 컬처 플랫폼이다. [발표]
2. 핵심은 **'빵 도시·커피 도시'가 되려는 것이 아니라는 점**이다. 빵(대전 성심당)과 커피(강릉)는 이미 다른 도시가 선점했지만, 이 주제는 커피·빵을 정체성이 아니라 **입구**로 쓰고 경쟁의 축을 **'하루 체류 경험'**으로 옮긴다. 앞선 비교표에서 커피·빵이 받은 가장 큰 약점(독점성 2점)을 구조적으로 피해 간다. [해석]
3. 강점: 20·30대에게 가장 친숙한 접점, 술이 없어 가족·청소년·외국인까지 넓은 대상, 사계절 운영, 메뉴·굿즈·멤버십으로 판매가 바로 이어짐, 작게 시작해 검증할 수 있는 구조(팝업 → 정례화). [발표·해석]
4. 약점과 과제: '대구만의' 이유를 **콘텐츠로 증명**해야 하고(카페는 어디에나 있음), 대구 커피 관련 근거가 아직 비어 있으며, 커뮤니티 운영은 사람과 시간이 많이 든다. 대전처럼 당일치기로 끝나지 않게 **저녁 이후 일정**도 설계해야 한다. [해석]
5. IP는 '하루'라는 형식 자체가 반복 단위가 된다. **하루 코스 = 에피소드 1편**으로 지도·숏폼·웹툰·시그니처 메뉴·굿즈가 계속 만들어진다. [해석]

### 2-1. 발표자료가 제안하는 것 [발표]

|---|---|
| 브랜드 | DAEGU, IN A DAY / LOCAL CULTURE, SHARED TASTE |

| 네 가지 축 | **IDENTITY**(대구만의 정체성) · **TASTE**(커피 & 베이커리) · **COMMUNITY**(취향 기반 커뮤니티) · **STAY**(하루의 경험) |
| 흐름 | 브랜드 정체성 → 방문 동기 → 사람들의 교류 → 대구 체류 경험 |
| 경험 설계 | DISCOVER(발견) → TASTE(맛보기) → CONNECT(교류) → EXPLORE(둘러보기) → RETURN(다시 찾기) |
| 대상 | 대구 시민 · 국내 방문객 · 외국인 방문객 |
| IP 구성 | STORY(로컬 스토리) · SIGNATURE(시그니처 경험) · VISUAL(브랜드 디자인) · COMMUNITY(참여형 콘텐츠) |
| 실행 | PHASE 1 콘셉트 검증 → PHASE 2 팝업 운영 → PHASE 3 브랜드화 |
| 지표 | 유입 · 체류 · 교류 · 지속 · 지역성 |
| 원칙 | 대구의 정체성을 단정하지 말고 시민·상인·방문객의 목소리로 검증한다 |

## 3. 주요 발견

### 3-1. 왜 이 주제인가: 약점을 '구조'로 피해 간다 [해석]

| 앞선 비교표에서 커피·빵의 평가 | 이 주제가 바꾸는 점 |
|---|---|
| 독점성 2점 — 빵은 대전, 커피는 강릉이 선점 | 커피·빵을 **정체성이 아니라 입구**로 쓴다. 경쟁 상대가 '빵 도시'가 아니라 '하루를 보내고 싶은 도시'가 된다 |
| 방문 동기 3점 — 카페는 어디에나 있다 | 커피 한 잔이 **독서 모임·동네 산책·로컬 스토리**로 이어지는 '하루'가 방문 동기가 된다 |
| 근거 3점 — 대구 커피 근거가 비어 있음 | 근거의 무게를 **대구의 이야기와 장소**(근대골목, 문학, 시장, 빵집 노포)로 옮긴다. 커피 근거는 조원 자료로 보강 |
| 판매 연결 5점, 계절 독립 5점 | 그대로 강점으로 유지 |

→ [해석] 비교표의 점수 기준으로 다시 매기면 독점성(2→3), 방문 동기(3→4)가 오를 여지가 있다. 다만 이는 **콘텐츠가 실제로 '대구만의 하루'를 보여줄 때**에만 성립한다.

## 4. 분석

### 4-1. 장점과 단점

| 장점 | 단점 |
|---|---|
| **넓은 대상**: 술이 중심이 아니라 가족·청소년·외국인·시민까지 포함 | **'대구만의' 증명 부담**: 콘텐츠가 약하면 '그냥 카페 투어'로 보인다 |
| **판매 직결**: 시그니처 메뉴, 원두·빵 선물, 굿즈, 멤버십 | **커피 근거 공백**: 대구 커피 관련 수치·사례가 아직 없음 |
| **사계절·평일 운영 가능**: 축제·경기 일정에 묶이지 않음 | **커뮤니티 운영 비용**: 모임 진행자·공간·꾸준함이 필요 |
| **작게 시작 가능**: 팝업 1회로 검증 → 정례화 | **강한 한 방이 약함**: 치킨·야구처럼 단번에 떠오르는 상징이 아직 없음 |
| **시민도 대상**: 관광객만이 아니라 시민의 일상 문화로도 작동 → 지속성 | **파트너 의존**: 카페·빵집 협력이 없으면 운영 불가, 특정 업체 편애 논란 위험 |
| **다른 주제와 결합 쉬움**: 근대·레트로, 한방, 문학, 시장과 자연스럽게 연결 | **저녁 공백**: 카페·빵집은 낮 중심이라 1박 유도가 약해질 수 있음 |

## 6. IP 콘텐츠 유형 예시 [해석]

**핵심 아이디어: '하루'가 IP의 반복 단위다.** 하루 코스 하나가 지도 한 장, 영상 한 편, 이야기 한 화, 메뉴 하나, 굿즈 하나가 된다.

| 유형 | 예시 | 반복 생산 방식 | 판매·유입 연결 |
|---|---|---|---|
| **하루 코스 지도** | '근대골목의 하루' 일러스트 지도 (빵집 → 카페 → 청라언덕 → 계산성당 → 야시장) | 동네마다 1장씩 | 지도 굿즈, 코스 스탬프 |
| **숏폼 영상** | '대구에서 하루 3만 원으로', '창이 흐려지는 3호선 타고 빵 사러 가기' | 코스·계절·메뉴마다 | SNS 유입, 코스 신청 |
| **시그니처 메뉴** | 대구 사과 디저트, 한방 재료 음료, 통옥수수빵 오마주 메뉴 | 계절 한정 | 메뉴 판매, 선물 세트 |
| **캐릭터** | 커피잔·빵·사과·약재 같은 **대구의 사물**을 의인화한 캐릭터 (오브젝트헤드 방식) | 동네마다 캐릭터 추가 | 굿즈, 기존 캐릭터 콜라보 |
| **웹툰·숏폼 애니** | 동네 카페에서 시작하는 하루짜리 이야기. 스토리 기획안 C '흐린 창 너머', D '40도의 영시'를 카페 무대로 변형 | 한 화 = 한 동네의 하루 | 성지 동선, 콜라보 메뉴 |
| **독서 모임 콘텐츠** | '대구를 읽는 모임' — 『마당 깊은 집』 읽고 장관동·약전골목 걷기 | 월 1권 | 회비·멤버십, 북 굿즈 |
| **멤버십·스탬프** | 하루 코스를 완주하면 도장, 동네별 배지 | 시즌마다 새 배지 | 재방문, 파트너 매장 매출 |
| **협업 패키지** | 지역 빵집 × 디자이너 패키지, 대구 출신 작가 × 독서 모임, 크리에이터 × 하루 코스 | 분기별 | 한정 판매 |

**억지 판별 체크** (keyword_map 10-2장 기준): 하루 코스가 '대구가 아니면 성립하지 않는가'를 매번 확인한다. 예) 근대골목 코스는 청라언덕·계산성당·삼송빵집이 한 동선에 있어 통과, '아무 카페 3곳 투어'는 탈락.

## 7. 예상되는 어려움과 대응 [해석·추정]

| # | 어려움 | 대응 방향 |
|---|---|---|
| 1 | 카페는 어디에나 있어 '대구만의' 이유가 약해 보일 수 있다 | 모든 코스에 **대구 고유 장소·이야기 1개 이상** 필수. 억지 판별 체크 통과한 코스만 공개 |
| 2 | 대구 커피 근거가 없다 | 커피 담당 조원 자료로 보강. 근거가 약하면 커피는 '만나는 장소'로만 쓰고 정체성 주장은 하지 않기 |
| 3 | 대전·강릉과 비교당한다 | '빵·커피 도시' 표현을 쓰지 않고 **'하루를 보내는 도시'**로 일관 |
| 4 | 커뮤니티는 사람이 계속 붙어 있어야 유지된다 | 모임 리더(시민·작가) 육성, 소규모 정기 모임부터, 운영 매뉴얼화 |
| 5 | 파트너 매장 편애 논란 | 공개 기준으로 파트너 선정, 코스마다 여러 매장 순환 |
| 6 | 낮 위주라 당일치기로 끝난다 | 코스 끝에 야시장·저녁 공연·북토크를 붙이고 '저녁 체류'를 지표로 측정 |
| 7 | 정체성을 팀이 단정할 위험 (발표자료도 경계) | 인터뷰·피드백으로 검증 후 확정. 시민·상인 목소리를 콘텐츠에 직접 담기 |
| 8 | 실존 가게·인물·작품의 권리 | 매장 사용 허락, 작품 인용은 저작권 확인(「동무생각」 가사는 인용 금지), 실존 인물은 동의 또는 가상화 |
| 9 | 근대골목 등 특정 지역 쏠림, 주민 불편 | 동네별 코스 분산, 방문 매너 안내(누마즈 학교 무단 출입 사례 참고) |
| 10 | 상징이 약해 기억되기 어렵다 | 브랜드 이름(DAEGU, IN A DAY) + 캐릭터 + 시그니처 메뉴 1개를 **세트로 반복 노출** |

## 8. 한계 및 추가 조사 필요 사항
- 대구 커피 관련 근거(카페 수·밀도, 로스터리 역사, 커피 행사)는 이 보고서에서 조사하지 않았다 → **커피 담당 조원 자료로 보완**
- 강릉 커피, 국내 독서 모임 플랫폼 사례는 일반적으로 알려진 내용이라 **출처 확인이 필요**하다
- 독점성·방문 동기 점수 상향(3-1)은 분석자 판단이며, PHASE 1 인터뷰로 검증해야 한다
- 빵집 영업 정보는 리뷰 사이트 기준이라 최신 확인이 필요하다
- 이 보고서는 발표자료의 텍스트만 반영했다 (슬라이드 디자인·이미지는 분석하지 않음)
