## 1. 참여 매장 선정 기준

### 1-1. 필수 조건 (하나라도 빠지면 제외)

| # | 조건 | 이유 |
|---|---|---|
| 1 | 대구 안에서 운영하는 커피·베이커리 매장 | 주제 범위 |
| 2 | **시그니처 메뉴 1개 이상** | 캐릭터 모티프의 원천 |
| 3 | 캐릭터·상호·매장 사진 사용 **동의** | 권리 |
| 4 | 포토존 또는 캐릭터 표시물을 둘 공간 | 인증 미션 |
| 5 | QR·스탬프 운영에 협조 (직원 안내 포함) | 여권·도감 |
| 6 | 위생·영업 신고 등 기본 요건 충족 | 공공성 |

### 1-2. 평가 항목 (100점)

| 항목 | 배점 | 보는 것 |
|---|---|---|
| 대구 연관 근거 | 25 | 동네 역사, 지역 재료, 오래 운영한 노포, 사장님의 대구 이야기 |
| 시그니처 메뉴의 캐릭터화 가능성 | 20 | 형태·색이 뚜렷한가, 다른 가게와 겹치지 않는가 |
| 코스 동선 위치 | 20 | 다른 참여 매장·명소와 걸어서 이어지는가 (10~15분 이내) |
| 참여 의지 | 15 | 모임 공간 제공, SNS 협업, 시즌 메뉴 개발 의향 |
| 운영 지속성 | 10 | 운영 기간(1년 이상 권장), 시즌 내내 운영 가능 여부 |
| 외국인 응대 | 10 | 다국어 메뉴판, 카드 결제 등 |

### 1-3. 균형 원칙
- 한 동네 코스는 **3~5개 매장**, 빵집과 카페를 섞는다
- 같은 메뉴 모티프(예: 사과 디저트 2곳)는 한 시즌에 1곳만
- 프랜차이즈 직영점은 제외하고 **지역 독립 매장**을 우선한다 (대구 연관성·공정성)
- 노포와 새 가게를 함께 넣어 세대가 다른 손님을 모은다

### 1-4. 제외 대상
- 동의서 미제출, 위생·평판 문제, 시즌 중 폐업·이전 예정
- 캐릭터에 사장님 얼굴·실명을 넣어야만 참여하겠다는 경우 (가드레일 위반)

## 2. 모집과 선정 절차

| 단계 | 내용 | 산출물 |
|---|---|---|
| ① 공개 모집 | 모집 공고(기준·혜택·의무 공개), 상인회·SNS로 안내 | 신청서 |
| ② 서류·현장 확인 | 필수 조건 확인, 매장 방문 사진 | 확인표 |
| ③ 평가 | 1-2 평가표로 점수화, 동네별 상위 매장 선정 | 선정 결과 공개 |
| ④ 인터뷰 | 매장 인터뷰 양식 작성 (`brand/20261028_cafe_character_system_v1.md` 7-1) | 인터뷰 기록 |
| ⑤ 캐릭터 생성 | AI 에이전트가 캐릭터 시트 초안 생성 → 팀 검수 | 캐릭터 시트 |
| ⑥ 매장 확인 | 매장이 1회 수정 요청 → 최종 승인 | 승인서 |
| ⑦ 키트 설치 | 포토존, QR, 스탬프, 여권 비치 | 설치 사진 |

## 3. 캠페인 운영 방식

### 3-1. 시즌제 (분기별)

| 시즌 | 기간 | 무대 (예) | 시즌 의상 | 연결 이벤트 |
|---|---|---|---|---|
| 1 | 봄 | 중구 근대골목 | 꽃 장식 | 첫 코스 공개, 시범 운영 |
| 2 | 여름 | 2번째 동네 | 대프리카 (빙수·부채) | 여름 축제 기간 연계 |
| 3 | 가을 | 3번째 동네 | 단풍·목도리 | '올해의 하루콩' 투표 |
| 4 | 겨울 | 전체 | 털모자 | 시즌 완주자 히든 캐릭터 공개, 연말 모임 |

- 시즌마다 **동네 1개 + 하루콩 3~5종**을 새로 공개한다 → 1년에 12~20종, 완주 이유가 매년 새로 생긴다

### 3-2. 매장 지원 키트

| 구성 | 내용 |
|---|---|
| 캐릭터 표시물 | 등신대 또는 벽 스티커(포토존), 테이블 POP |
| 인증 도구 | QR 스탠드, 도장 |
| 배포물 | 여권, 동네 지도 |
| 콘텐츠 | 매장용 캐릭터 이미지 파일, SNS 게시 문안 |
| 안내 | 직원용 1장짜리 안내문 (미션 방법, 자주 묻는 질문) |

### 3-3. 역할 분담

| 주체 | 역할 |
|---|---|
| 운영팀(우리) | 기획, 캐릭터 생성·검수, 여권·지도·SNS 운영, 성과 측정 |
| 참여 매장 | 시그니처 메뉴 제공, 키트 운영, 인증 협조, 모임 공간(가능 시) |
| 지역 협력 (검토) | 상인회, 관광안내소, 도서관·문학관(독서 모임), 지역 뮤지션(음악) |

### 3-4. 비용·수익 구조 (가설)

| 구분 | 내용 |
|---|---|
| 초기 비용 | 캐릭터 디자인 확정, 키트 제작, 여권·지도 인쇄 |
| 매장 부담 | 없음 또는 최소 (초기 참여 장벽 낮추기) |
| 매장 이익 | 방문객 증가, SNS 노출, 캐릭터 굿즈 판매 수익 일부 |
| 수익원 | 캐릭터 굿즈(키링·인형·블라인드 카드팩), 모임 참가비, 협업 상품 |
| 원칙 | 방문 보상(캐릭터)은 무료·확정 지급, 판매용 굿즈만 유료 |

### 3-5. 성과 측정 (발표자료 지표 + 추가)

| 구분 | 지표 |
|---|---|
| 유입 | 여권 배포 수, QR 첫 인증 수, 신규 방문 비율 |
| 체류 | 같은 날 2곳 이상 인증 비율, 코스 완주율, **저녁 시간대 인증 비율** |
| 교류 | 모임 참여 수, 모임 한정 캐릭터 획득 수 |
| 지속 | 재방문(다른 시즌 인증), 생일 이벤트 재방문, 투표 참여 수 |
| 지역성 | 참여 매장 수, 매장 매출 변화(매장 자율 보고), 굿즈 판매량 |
| 확산 | 해시태그 게시물 수, 캐릭터별 SNS 반응 |

### 3-6. 운영 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 특정 매장에 손님이 몰려 불편 | 코스 순서를 시즌마다 바꾸고, 인증은 하루 1회로 제한 |
| 매장 이탈·폐업 | 해당 하루콩은 '여행 떠남' 설정으로 정리, 대체 매장 모집 |
| 원격 인증 악용 | 매장별 일일 코드, 위치 확인 |
| 캐릭터 간 인기 격차 | 비인기 캐릭터를 SNS 주인공으로 순환 노출 |
| 매장과 캐릭터 이미지 충돌 | 승인 절차, 수정 1회 보장 |
| 굿즈 재고 부담 | 시범 시즌은 소량·예약 판매 |

## 4. 첫 시범 운영 제안 (PHASE 2)
- 무대: 중구 근대골목 일대 (도보 동선이 가장 촘촘함)
- 규모: 매장 3~5곳, 하루콩 3~5종, 여권·지도 1종, 포토존·QR
- 기간: 4~6주
- 검증 질문: ① 캐릭터 때문에 다음 가게로 이동했는가 ② 저녁까지 머물렀는가 ③ 다음 시즌에 다시 오고 싶은가
