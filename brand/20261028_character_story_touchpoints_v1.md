## 1. 스토리텔링 방향

### 1-1. 원칙
1. **캐릭터는 대구를 설명하지 않는다.** 자기 가게의 하루를 살 뿐이다. 대구는 배경·소품·말투로만 드러난다.
2. **하루가 한 화다.** 발표자료의 '하루' 구조를 그대로 이야기 단위로 쓴다 → 하루 코스 1개 = 에피소드 1개.
3. **보는 사람이 곧 여행자다.** 독자는 '오늘 대구에서 하루를 보내는 사람'이고, 하루콩들은 그 사람을 맞는 쪽이다.
4. **작은 사건만.** 세계를 구하는 이야기가 아니라 "오늘 사과파이가 덜 구워졌다" 수준의 일상 사건. 반복 생산이 쉽고 억지스럽지 않다.
5. **가게가 바뀌면 이야기도 바뀐다.** 그 가게가 아니면 안 되는 사건만 쓴다 (억지 판별, `research/keyword_map.md` 10-2장).

### 1-2. 이야기 축 5가지

| 축 | 내용 | 형식 | 연결되는 경험 단계 |
|---|---|---|---|
| **① 가게의 하루** (일상툰) | 하루콩이 자기 가게에서 보내는 아침 오픈 → 점심 → 마감. 손님·사장님·날씨에 반응 | SNS 4컷, 숏폼 | 발견 · 맛보기 |
| **② 여행자의 하루** (코스 에피소드) | 여행자가 한 동네 코스를 걷는 하루. 가게마다 그 가게 하루콩이 등장해 다음 가게로 넘겨줌 | 웹툰 1화, 지도와 짝 | 둘러보기 |
| **③ 이웃 관계** | 같은 동네 하루콩끼리의 우정·라이벌·짝사랑 같은 작은 관계 | SNS 연재, 팬 투표 | 다시 찾기 |
| **④ 모임의 밤** | 독서·취향 모임 날, 하루콩들이 가게 한구석에서 손님들이 고른 책을 몰래 읽는 이야기 | 모임 공지와 짝, 모임 후기 | 교류 |
| **⑤ 계절과 날씨** | 대구의 여름(대프리카)에 녹아내리는 하루콩, 첫눈에 들뜨는 하루콩 | 시즌 특집 | 시즌 한정 등급 |

### 1-3. 에피소드 예시 [예시]

| 제목 | 축 | 한 줄 줄거리 | 대구가 들어가는 방식 |
|---|---|---|---|
| "38도, 사과파이 사수 작전" | ①⑤ | 대프리카 한낮, 진열대의 사과파이가 녹을까 봐 사과콩이 선풍기 앞에서 하루를 버틴다 | 더위는 설명하지 않고 '사건'으로만 |
| "근대골목의 하루" | ② | 여행자가 빵집 → 카페 → 언덕길 → 야시장 순으로 걷는다. 하루콩들이 다음 가게 쿠폰을 손에 쥐여 준다 | 실제 코스 순서 그대로 = 성지 동선 |
| "옥수콩은 왜 말이 없을까" | ③ | 말수 적은 옥수콩이 사과콩 생일(개업일)에 몰래 빵을 구워 준다 | 생일 = 실제 가게 개업일 |
| "오늘의 책은 『마당 깊은 집』" | ④ | 모임 손님들이 대구 배경 소설을 읽는 동안, 약콩은 책 속 골목이 바로 옆 골목이라는 걸 알아챈다 | 작품 인용 없이 '같은 골목'이라는 사실만 |
| "흐린 창 너머" (기존 기획안 C 변형) | ②③ | 3호선을 타고 출근하는 하루콩이 창이 흐려지는 구간마다 옆 칸 하루콩과 눈이 마주친다 | 3호선 창 흐림 장치를 장면으로 |

### 1-4. 피할 것
- 캐릭터가 "대구는 ~한 도시예요"라고 소개하는 대사
- 역사 설명 내레이션 (근대골목·약령시 연혁 등)
- 특정 가게만 계속 띄우는 이야기 (공정성)
- 실존 인물(사장님·작가) 얼굴·이름 등장

## 2. 접점 설계

경험 단계(발표자료)와 접점을 1:1로 연결했다.

| 경험 단계 | 접점 |
|---|---|
| 발견 | SNS 콘텐츠, 캐릭터 안내 지도 |
| 맛보기 | 매장 포토존, 시그니처 메뉴 |
| 교류 | 모임 한정 캐릭터, 모임 굿즈 |
| 둘러보기 | 캐릭터 여권(스탬프), 코스 지도 |
| 다시 찾기 | 수집 도감, 시즌 캐릭터, 생일 이벤트, 테마송 |

### 2-1. 캐릭터 여권 (대구 하루 여권)

| 항목 | 내용 |
|---|---|
| 형태 | 손바닥 크기 종이 여권 + 같은 내용의 웹 도감 (QR로 연동) |
| 구성 | 표지 → 내 정보 → 동네별 코스 페이지(가게마다 스탬프 칸 + 하루콩 실루엣) → 완주 페이지 → 메모(나의 하루 기록) |
| 획득 | 매장에서 도장 + QR 인증 → 실루엣이 캐릭터로 바뀜 |
| 완주 보상 | 동네 완주 = 동네 한정 스티커, 2개 동네 = 레어 카드, 시즌 전체 = 히든 캐릭터 공개 |
| 배포 | 참여 매장, 관광안내소, 모임 현장 |
| 다국어 | 한·영·일·중 (외국인 방문객 대상 — 발표자료의 다국어 안내) |

### 2-2. 캐릭터가 안내하는 대구 하루 지도

- 동네 하나 = 지도 한 장. 지도 위 가게 위치에 그 가게 하루콩이 서 있다
- 하루콩이 말풍선으로 **다음 가게까지의 길**을 알려 준다 ("여기서 언덕 올라가믄 내 친구 있다")
- 시간대 표시: 아침(빵집) → 낮(카페·산책) → 저녁(야시장·모임) — **저녁 일정까지 넣어 당일치기를 줄인다**
- 지도 굿즈(접이식·엽서형)와 웹 지도를 같이 운영

### 2-3. 캐릭터 중심 SNS 콘텐츠 (산리오 방식 참고)

| 산리오 방식 [사실] | 하루콩 적용 [해석] |
|---|---|
| 캐릭터별 상세 프로필 (생일·출신·좋아하는 음식) | 캐릭터 시트를 그대로 공개, 프로필 카드 시리즈 |
| 캐릭터 생일 축하 | **가게 개업일 = 캐릭터 생일** → 그날 매장 이벤트와 같이 운영 |
| 팬 투표 '캐릭터 대상' | 연 1회 '올해의 하루콩' 투표 → 1위 캐릭터 굿즈 출시 |
| 캐릭터별 계정·숏폼 | 처음에는 통합 계정 1개, 반응 좋은 캐릭터만 개별 코너로 |
| 한 캐릭터 의존에서 벗어난 다캐릭터 운영 | 매주 다른 가게 하루콩을 주인공으로 순환 |

**주간 운영 예시**

| 요일 | 콘텐츠 |
|---|---|
| 월 | 이번 주 주인공 하루콩 프로필 |
| 수 | 가게의 하루 4컷 (축 ①) |
| 금 | 주말 하루 코스 지도 (축 ②) |
| 일 | 팬 인증샷 리포스트, 다음 주 예고 |
| 수시 | 생일(개업일), 날씨 반응(폭염·첫눈), 모임 공지 |

### 2-4. 캐릭터 인증 미션

| 미션 | 방법 | 보상 |
|---|---|---|
| 포토존 | 매장 안 하루콩 등신대·벽 그림 앞에서 사진 → SNS 해시태그 | 매장 스티커 |
| QR 인증 | 계산대·테이블의 QR 스캔 → 웹 도감에 캐릭터 등록 | 디지털 카드 |
| 메뉴 미션 | 그 하루콩의 시그니처 메뉴 주문 | 캐릭터 카드 실물 |
| 코스 미션 | 같은 날 같은 동네 가게 3곳 방문 | 동네 한정 스티커 |
| 모임 미션 | 독서·취향 모임 참여 | 레어 캐릭터 |
| 생일 미션 | 개업일 주간 방문 | 생일 한정 카드 |

- QR은 **매장 안에서만** 작동하도록 위치 확인 또는 매장별 일일 코드로 설정 (원격 인증 방지)
- 포토존은 매장 동선을 막지 않는 크기로, 매장이 위치를 정한다

### 2-5. 음악

| 형태 | 내용 |
|---|---|
| 메인 테마송 | 'DAEGU, IN A DAY' 하루의 흐름(아침 → 저녁)을 담은 1곡 |
| 캐릭터 지글 | 하루콩마다 8마디 짧은 멜로디 → 숏폼 배경음, QR 인증 시 재생 |
| 동네 BGM | 코스 지도 웹 페이지·영상용 동네별 짧은 음악 |
| 협업 | 대구 인디 뮤지션과 작업 (대구는 유네스코 음악창의도시, 클럽 헤비 등 인디씬이 있음) |

- **모든 음악은 새로 만든 곡**으로. 기존 곡(김광석, 「동무생각」 등)의 가사·멜로디는 쓰지 않는다 (저작권)

## 3. 단계별 적용 (발표자료 PHASE와 연결)

| 단계 | 캐릭터·접점에서 할 일 |
|---|---|
| PHASE 1 콘셉트 검증 | 기본형 확정, 가상 예시 캐릭터 3종으로 타깃 인터뷰 반응 확인 |
| PHASE 2 팝업 운영 | 한 동네 코스(3~5개 매장)로 하루콩 시범 제작, 종이 여권·포토존·QR 시범 |
| PHASE 3 브랜드화 | 동네 확장, SNS 정례 운영, 생일·투표 이벤트, 테마송·굿즈 |
