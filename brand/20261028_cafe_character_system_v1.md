## 1. 핵심 구조: "기본형은 하나, 가게마다 하나씩"

| 고정되는 것 (모든 캐릭터 공통) | 가게마다 바뀌는 것 |
|---|---|
| 몸의 기본 형태, 등신 비율, 선 굵기, 표정 세트 | 머리·몸의 모티프 (시그니처 메뉴) |
| 세계관 표식 (공통 액세서리) | 색 팔레트, 의상, 소품 |
| 데포르메 규칙, 크기 기준 | 출신, 성격, 말투, 좋아하는 것·싫어하는 것 |
| 카드·인형 규격, 번호 체계 | 생일, 친구 관계, 등급 |

→ [해석] 한 사람이 그린 것처럼 **통일감**이 있어야 수집욕이 생기고, 가게마다 **확실히 다르게 보여야** "다음 가게 캐릭터도 모으고 싶다"가 된다.

## 3. 세계관 (가칭: 하루콩) [해석]

> **"대구의 가게에서 그날의 첫 잔, 첫 빵이 나오면, 그 가게의 하루가 작은 콩 하나로 태어난다."**

- **하루콩**: 가게의 시그니처 메뉴와 분위기를 닮은 작은 존재. 자기가 태어난 가게에 살며 손님을 맞는다.
- 이름 '콩'은 커피콩·팥(단팥빵)·작고 귀여운 것을 함께 가리킨다. (가칭이며 상표 검색 필요)
- 하루콩은 **가게 밖으로 나가면 힘이 약해진다** → 여행자가 직접 가게에 와야 만날 수 있다는 규칙(방문 동기)
- 하루콩끼리는 같은 동네에서 서로 알고 지낸다 → 이웃 가게를 이어 걷는 '하루 코스'의 이유
- 세계관은 **설명하지 않고 행동으로** 보여 준다 (스토리 원칙은 별도 문서)

## 4. 기본형 규칙 (고정)

| 항목 | 규칙 |
|---|---|
| 등신 | **2등신** (머리 : 몸 = 1 : 1). 머리가 곧 모티프 |
| 몸 | 둥근 콩 모양. 팔다리는 짧은 원기둥, 손가락 없음 |
| 공통 표식 | ① 머리 위로 올라가는 **김(스팀) 한 줄기** — 갓 나온 커피·빵의 김이자 대구 여름 아지랑이 ② 가슴의 **시계 배지** — 'IN A DAY'의 하루 시계, 배지 바늘 위치로 가게의 '가장 바쁜 시간'을 표시 |
| 얼굴 | 점 눈 2개 + 작은 입. 볼터치 공통. 표정 세트 8종(기본·웃음·놀람·졸림·화남·울먹·자신만만·부끄럼) |
| 색 | 캐릭터당 주색 1 + 보조색 2 + 공통 선색 1 (총 4색 이내) |
| 선 | 균일한 굵은 외곽선, 그라데이션 금지 (굿즈·스티커 인쇄 대응) |
| 포즈 세트 | 정면·인사·들고 있기(메뉴)·달리기·앉기·잠자기 6종 |
| 크기 기준 | 키를 '커피잔 1개 높이'로 통일 → 매장 포토존·인형 규격 통일 |

## 5. 가게별 변형 슬롯

| 슬롯 | 정하는 법 | 출처 |
|---|---|---|
| 모티프 | 시그니처 메뉴 1개를 머리·몸 형태로 | 매장 인터뷰 |
| 색 | 메뉴의 실제 색 + 가게 인테리어 색 | 매장 사진 |
| 의상·소품 | 가게의 상징물(앞치마·로스팅 기구·간판 글씨 등) 1~2개 | 매장 방문 |
| 출신 | 메뉴 재료의 대구 연고지 또는 가게가 있는 동네 | 매장 인터뷰 + 지역 자료 |
| 성격 | 사장님·손님이 고른 가게 분위기 키워드 3개 → 성격 3줄 | 매장 인터뷰 |
| 말투 | 대구 사투리 강도 0~3단계 중 선택, 입버릇 1개 | 매장 선택 |
| 좋아하는 것 / 싫어하는 것 | 메뉴·동네와 연결된 것 각 1개 | 생성 후 매장 확인 |
| 특기 | 가게만의 기술(직접 로스팅, 반죽 숙성 등) | 매장 인터뷰 |
| 생일 | **가게 개업일** | 매장 인터뷰 |
| 친구 | 같은 코스의 이웃 가게 하루콩 1~2명 | 코스 설계 |
| 등급 | 기본 / 동네 한정 / 시즌 / 레어 / 히든 (6장) | 캠페인 설계 |

### 예시 시트 [예시 — 가상 매장]

| | 사과콩 | 옥수콩 | 약콩 |
|---|---|---|---|
| 가상 매장 | 사과파이가 대표 메뉴인 동네 카페 | 오래된 옥수수빵이 대표인 빵집 | 약전골목 근처 한방차 카페 |
| 외형 | 사과파이 모양 머리, 갈색 체크 앞치마, 작은 과수원 바구니 | 노란 옥수수 알갱이가 박힌 빵 모양 머리, 하얀 제빵 모자 | 대추·계피 장식이 달린 찻잔 모양 머리, 한복풍 소매 |
| 출신 | 평광동 과수원 (대구 사과의 역사를 품은 동네 — 1935년 심은 홍옥나무가 남은 곳) | 시장 골목 빵집 | 약령시 약재 창고 |
| 성격 | 부지런함, 오지랖, 계절에 민감 | 말수 적음, 고집 셈, 속은 따뜻함 | 느긋함, 남의 안색을 잘 읽음, 잔소리꾼 |
| 말투 (사투리 강도) | 2 — "마, 따끈할 때 무라!" | 3 — "…맛있제? 됐다." | 1 — "오늘 얼굴이 좀 덥네예, 쉬다 가이소." |
| 좋아하는 것 / 싫어하는 것 | 가을 첫서리 / 퍽퍽한 사과 | 새벽 오븐 소리 / 줄 서서 재촉하는 손님 | 비 오는 오후 / 차가운 음료 원샷 |
| 특기 | 사과 깎기 한 줄로 | 반죽 상태 냄새로 맞히기 | 손님 체질 맞히기 (농담 수준 — 의료 표현 금지) |
| 친구 | 옥수콩 (아침 빵 배달 친구) | 약콩 (오래된 이웃) | 사과콩 (계절 차 메뉴 공동 개발) |

> 위 예시는 설명용이며 실제 매장·메뉴가 아니다. 실제 캐릭터는 매장 인터뷰와 확인을 거쳐 만든다.

## 6. 수집 체계

| 등급 | 얻는 법 | 표식 | 예 |
|---|---|---|---|
| 기본 | 매장 방문 → QR 인증 | 시계 배지 은색 | 매장마다 1종 |
| 동네 한정 | 같은 동네 코스 완주 | 배지에 동네 문양 | 근대골목 하루콩 단체컷 |
| 시즌 | 계절 한정 메뉴 기간에 방문 | 의상 변경 (봄 꽃·여름 대프리카·가을 단풍·겨울 털모자) | 여름 사과콩(빙수 버전) |
| 레어 | 동네 2곳 이상 완주 / 모임 참여 | 배지 금색 | 독서 모임 참여 한정 '책 읽는 하루콩' |
| 히든 | 시즌 전체 완주 | 배지 없음, 실루엣으로만 공개 | '대구의 하루' 그 자체를 닮은 하루콩 |

- **확정 획득 원칙**: 방문·참여하면 반드시 해당 캐릭터를 얻는다. 무작위 뽑기는 굿즈 판매(블라인드 상품)에만 쓰고, 방문 보상에는 쓰지 않는다 (포켓몬빵 중복 불만 교훈)
- **번호 체계**: `시즌-동네-번호` (예: S1-JG-03 = 시즌1 중구 3번)
- **실물 굿즈**: 카드(기본), 스티커·띠부씰(동네 한정), 아크릴 키링·인형(레어·판매용)

## 7. 캐릭터 생성 AI 에이전트 설계

### 7-1. 입력: 매장 인터뷰 양식

| 필드 | 질문 | 비고 |
|---|---|---|
| `store_name`, `location` | 가게 이름, 주소(구·동) | 동명 혼동 확인 |
| `signature_menu` | 가장 자신 있는 메뉴 1개와 그 이유 | 모티프 |
| `menu_story` | 메뉴가 생긴 사연, 재료의 출처 | 출신 |
| `opening_date` | 개업일 | 생일 |
| `vibe_keywords` | 가게 분위기를 세 단어로 (사장님 1회, 단골 1회) | 성격 |
| `daegu_link` | 가게와 대구의 연결 (동네 역사·재료·사장님의 대구 이야기) | 대구 연관 근거 |
| `craft` | 이 가게만의 기술·고집 | 특기 |
| `colors`, `photos` | 메뉴·인테리어 사진 3장 이상 | 색 |
| `dialect_level` | 사투리 강도 0~3 선택 | 말투 |
| `no_go` | 캐릭터에 넣지 말아야 할 것 | 금지 사항 |
| `consent` | 캐릭터·사진·상호 사용 동의 | 필수 |

### 7-2. 처리 단계

1. **근거 확인**: `daegu_link`가 비어 있으면 생성 중단 → 매장에 추가 질문
2. **모티프 추출**: 시그니처 메뉴의 형태·색·재료를 기본형 머리에 적용
3. **성격·말투 생성**: 분위기 키워드 3개 → 성격 3줄, 사투리 강도에 맞춘 대사 5개
4. **관계 연결**: 같은 코스의 기존 하루콩과 친구 관계 1~2개 제안
5. **검수 체크리스트** (아래 7-4)
6. **매장 확인**: 캐릭터 시트를 매장에 보내 수정 1회 → 최종 승인
7. **산출물 출력** (아래 7-3)

### 7-3. 출력

| 산출물 | 형식 |
|---|---|
| 캐릭터 시트 | 5장의 변형 슬롯을 모두 채운 표 |
| 이미지 생성 지시문 | 기본형 규칙 + 모티프 + 색 코드 + 3면도(정면·측면·뒷면) 지시 |
| 표정·포즈 세트 지시 | 표정 8종, 포즈 6종 |
| SNS 첫 소개 글 | 캐릭터 1인칭, 3문장 이내 |
| 대사 5개 | 인사·추천·작별·생일·날씨 반응 |
| 여권 스탬프·지도 아이콘 지시 | 단색 도안용 |
| 테마송 가사 초안 | 8마디 짧은 지글용 |

### 7-4. 가드레일 (에이전트 규칙)

- **다른 IP와 닮지 않게**: 티니핑·산리오·쿠키런 등 기존 캐릭터의 고유 형태·이름을 쓰지 않는다. 생성 후 유사성 점검
- **실존 인물 금지**: 사장님 얼굴·이름을 캐릭터에 그대로 넣지 않는다 (동의해도 캐릭터는 가상의 존재로)
- **메뉴 사실 확인**: 메뉴 재료·사연은 매장이 확인한 것만 쓴다
- **사투리는 애정으로**: 비하·과장 금지, 매장이 고른 강도만 사용
- **의료·효능 표현 금지**: 한방·건강 관련 메뉴도 효능을 말하지 않는다
- **억지 판별**: "이 캐릭터는 이 가게가 아니면 성립하지 않는가?" (`research/keyword_map.md` 10-2장)
- **대구 연관 근거 필수**: 근거 없는 캐릭터는 만들지 않는다

## 8. 한계 및 확인 필요
- '하루콩'은 가칭이다. 상표·기존 캐릭터 이름과 겹치는지 검색이 필요하다
- 프리큐어·수호캐릭터 관련 내용은 일반적으로 알려진 설정이며 출처를 따로 확인하지 않았다
- 티니핑 캐릭터 수는 블로그 집계라 기준마다 다르다 (130~150종)
- 예시 시트의 매장·메뉴는 가상이다
